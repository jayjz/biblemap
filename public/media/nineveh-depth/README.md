# Nineveh image licenses and source links

These images are used in the Nineveh encounter as *historical context and later artistic reception*, not as illustrations of Jonah's visit.

- **flood-tablet.webp** — photograph by **Fæ**, Wikimedia Commons file [Library of Ashurbanipal — The Flood Tablet](https://commons.wikimedia.org/wiki/File:Library_of_Ashurbanipal_The_Flood_Tablet.jpg), under **[Creative Commons Attribution–ShareAlike 3.0](https://creativecommons.org/licenses/by-sa/3.0/)**. Full image converted to WebP for BibleMap; changes: format conversion/compression. The British Museum artifact is K.3375, seventh-century BCE; it does **not** establish when Jonah lived, visited, or was written about. Reuse of this derivative remains subject to CC BY-SA 3.0.
- **jonah-vine.webp** — *Jonah Under the Gourd Vine*, 280–290 CE, Cleveland Museum of Art, accession [1965.239](https://www.clevelandart.org/art/1965.239), released in the museum's Open Access/Public Domain program (CC0). Full-frame WebP derivative; not evidence of Jonah's appearance, clothing, or botany.

File checksums, original URLs, historical limitations, and creator records are retained in `src/features/nineveh/depth-media.json` and `docs/research/nineveh-depth-sources.md`.
