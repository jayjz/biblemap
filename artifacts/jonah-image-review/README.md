# Supplied Jonah originals

These are research assets, not production-approved media. See `docs/research/jonah-visual-assets-v1.md` and `docs/research/jonah-asset-candidates.json` for identity corrections, rights evidence, scene suitability, checksums, and unresolved provenance.

The three institution-matched public-domain originals are tracked here without modification. All six supplied originals remain locally present. Three unidentified reproductions and the six byte-identical copies in `publication-hold/` are intentionally ignored until their provenance/editorial review is resolved. Filenames are preserved as supplied and must never be treated as identity evidence.

Run `npm run validate:media` from the repository root. The supplied `SHA256SUMS` is retained unchanged. Do not place these files in `public/` merely because they pass integrity checks: recorded human approval is separately required.
