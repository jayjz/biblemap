# Frozen dependency checkpoint

The committed-lockfile audit reproduced **38** findings (1 low, 16 moderate, 19 high, 2 critical). The frozen checkpoint audit reports **22 unresolved** package findings (14 moderate, 8 high, zero critical), exit **1**. These are npm's affected-package counts; propagated dependency findings are not independent exploits. See [before](../../artifacts/release-readiness/audit-before.json) and [after](../../artifacts/release-readiness/audit-final.json) for every advisory, severity, affected node and npm fix proposal.

No `npm audit fix --force` was used. Work stopped at the creator's dependency freeze. A passing technical suite is not acceptance of the remaining vulnerabilities.
